Guía básica de HTML

HTML sirve para organizar el contenido de una página web.

En cada sección encontrarás etiquetas y atributos importantes con ejemplos sencillos.

estructura texto listas enlaces-imagenes tablas formularios secciones multimedia comentarios

1. Estructura

Etiquetas

  • <!DOCTYPE html>: indica que se usa HTML moderno.
  • <html>: contiene toda la página.
  • <head>: contiene información de la página.
  • <title>: muestra el título en la pestaña.
  • <body>: contiene el contenido visible.

Atributos importantes

  • lang: indica el idioma. Ejemplo: <html lang="es">.
  • charset: permite mostrar correctamente los caracteres. Ejemplo: <meta charset="UTF-8">.
  • name y content: describen información de la página. Ejemplo: <meta name="description" content="Mi página">.

2. Títulos y texto

Etiquetas

  • <h1> a <h6>: crean títulos de diferentes niveles. Ejemplo: <h1>Título principal</h1>.
  • <p>: crea un párrafo. Ejemplo: <p>Hola mundo</p>.
  • <br>: hace un salto de línea. Ejemplo: Hola<br>Mundo.
  • <hr>: separa temas. Ejemplo: <p>Tema uno</p><hr>.
  • <strong>: indica importancia. Ejemplo: <strong>Importante</strong>.
  • <em>: da énfasis. Ejemplo: <em>Muy útil</em>.
  • <mark>: resalta texto. Ejemplo: <mark>Revisar</mark>.
  • <sub> y <sup>: muestran subíndice y superíndice. Ejemplo: H<sub>2</sub>O.

Atributos importantes

  • id: identifica un elemento. Ejemplo: <p id="aviso">Hola</p>.
  • class: agrupa elementos para darles estilo. Ejemplo: <p class="destacado">Hola</p>.
  • title: añade información adicional. Ejemplo: <p title="Un mensaje">Pasa el cursor</p>.

Cómo se conectan

Las etiquetas de texto se colocan dentro de <body> y pueden combinarse dentro de un párrafo.

3. Listas

Etiquetas

  • <ul>: crea una lista con viñetas.
  • <ol>: crea una lista numerada.
  • <li>: representa un elemento de la lista.

Atributos importantes

  • start: elige el número inicial de una lista ordenada. Ejemplo: <ol start="3">.
  • type: cambia el estilo de numeración de <ol>. Ejemplo: <ol type="A">.

Cómo se conectan y ejemplo

<li> va dentro de <ul> o <ol>.

4. Enlaces e imágenes

Etiquetas

  • <a>: crea un enlace. Ejemplo: <a href="index.html">Inicio</a>.
  • <img>: muestra una imagen. Ejemplo: <img src="imagenes/foto.jpg" alt="Una foto">.
  • <figure>: agrupa una imagen u otro contenido.
  • <figcaption>: añade una descripción a la figura.

Atributos importantes

  • href: indica el destino del enlace. Ejemplo: href="index.html".
  • src: indica el archivo de la imagen. Ejemplo: src="imagenes/foto.jpg".
  • alt: describe la imagen. Ejemplo: alt="Un gato sentado".
  • target: indica dónde se abre el enlace. Ejemplo: target="_blank".

Cómo se conectan y ejemplo

<a> contiene el texto del enlace. <figure> puede contener <img> y <figcaption>.

5. Tablas

Etiquetas

  • <table>: crea la tabla.
  • <tr>: crea una fila.
  • <th>: crea una celda de encabezado.
  • <td>: crea una celda de datos.

Atributos importantes

  • colspan: une columnas. Ejemplo: <td colspan="2">.
  • rowspan: une filas. Ejemplo: <td rowspan="2">.
  • scope: identifica el tipo de encabezado. Ejemplo: <th scope="col">Nombre</th>.

Cómo se conectan y ejemplo

<table> contiene filas <tr>, y cada fila contiene celdas <th> o <td>.

6. Formularios

Etiquetas

  • <form>: agrupa campos para enviar datos.
  • <label>: indica qué dato se pide.
  • <input>: crea un campo de entrada.
  • <textarea>: permite escribir varias líneas.
  • <select> y <option>: crean una lista desplegable y sus opciones.
  • <button>: crea un botón.

Atributos importantes

  • type: define el tipo de campo. Ejemplo: type="email".
  • name: nombre del dato. Ejemplo: name="correo".
  • placeholder: muestra una sugerencia. Ejemplo: placeholder="Escribe tu nombre".
  • required: hace obligatorio el campo.
  • for: conecta un <label> con el id de un campo.

Cómo se conectan y ejemplo

Los campos van dentro de <form>. El valor de for debe coincidir con el id del campo.

7. Secciones de una página

Etiquetas

  • <header>: encabezado de la página o sección.
  • <nav>: contiene enlaces de navegación.
  • <main>: contiene el contenido principal.
  • <section>: agrupa contenido de un tema.
  • <article>: contiene contenido independiente.
  • <footer>: pie de página o sección.
  • <div>: agrupa contenido sin significado especial.
  • <span>: agrupa texto en línea.

Atributos importantes

  • id: identifica una sección. Ejemplo: <section id="contacto">.
  • class: permite aplicar estilos. Ejemplo: <div class="tarjeta">.
  • style: aplica un estilo directamente. Ejemplo: <p style="color: blue;">.

Cómo se conectan y ejemplo

<main> puede contener <section> y <article>. El encabezado y el pie suelen estar separados del contenido principal.

8. Multimedia y otras etiquetas

Etiquetas

  • <audio>: añade audio.
  • <video>: añade video.
  • <source>: indica el archivo de audio o video.
  • <details> y <summary>: crean contenido desplegable y su título.
  • <script>: conecta o contiene JavaScript.
  • <style>: contiene reglas CSS.

Atributos importantes

  • controls: muestra controles de audio o video.
  • src: indica el archivo multimedia.
  • type: indica el tipo de archivo.
  • open: muestra un <details> abierto inicialmente.

Cómo se conectan y ejemplo

<source> puede ir dentro de <audio> o <video>. <summary> va dentro de <details>.

9. Comentarios finales

Los comentarios sirven para dejar notas en el código; no aparecen como texto normal en la página, se abre y cierra asi <!-- -->.
